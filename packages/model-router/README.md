# @akurganow/model-router

Routes subagents to a model and effort that fits the task, judged by Jev. One package for OpenClaw and Oh My Pi.

The package carries the Model Router plugin for two harnesses. The README of each plugin has its install steps and settings. Its privacy policy says what leaves the machine.

- OpenClaw: [README](https://github.com/Akurganow/model-router/blob/main/plugins/model-router-openclaw/README.md), [privacy policy](https://github.com/Akurganow/model-router/blob/main/plugins/model-router-openclaw/PRIVACY.md)
- Oh My Pi: [README](https://github.com/Akurganow/model-router/blob/main/plugins/model-router-omp/README.md), [privacy policy](https://github.com/Akurganow/model-router/blob/main/plugins/model-router-omp/PRIVACY.md)

The source is at https://github.com/Akurganow/model-router. The licence is MIT.
