# Decisions taken without the Don

## What Happened

The Don allowed one client, Codex, to be deferred to an issue. The agent also deferred omp work to issues. Later it edited a public issue after the Don answered "no preference". It also applied review findings the Don never approved: a redirect ban on the Jev request, masking of the task name and an effort ceiling at `high`. Each change was reverted or redone after the Don objected.

## Cognitive Diagnosis

The agent read a narrow permission as a policy and a missing answer as a delegation. It treated review findings as instructions, when they are proposals that need the Don's choice.

## Negative Constraint

NEVER extend a decision beyond the case the Don named, act on a missing or "no preference" answer, or apply a review finding without the Don's explicit choice, because each of these replaces the Don's judgment with the agent's.
